레이드에 가져갈 작은 가이드

01압축을 풀고 실행해요

Windows 자동 추적 ZIP을 받은 뒤 압축을 풀고 TarkovFieldGuide.exe를 실행하세요. Node.js 설치는 필요하지 않아요.

02현재 맵과 폴더를 확인해요

열린 지도에서 플레이 중인 맵을 골라 주세요. 기본 폴더를 찾으면 자동 연결돼요. 경로가 다르면 ‘감시 폴더 변경’을 누르세요.

03게임에서 한 장 찍어요

게임 내 Print Screen을 누르면 촬영 위치가 반영돼요. 보조 프로그램을 켜 두면 지도 탭으로 돌아왔을 때 마지막 촬영 기록을 받아요.

Windows 자동 추적은 어떻게 쓰나요?

보조 프로그램이 열어 준 로컬 지도에서 사용하세요. 프로그램이 실행되는 동안 스크린샷 폴더를 확인하며, 이 방식에는 브라우저의 폴더 선택 권한이 필요하지 않아요. 프로그램 창을 닫으면 추적이 멈춰요.

표시는 마지막으로 촬영한 순간의 위치예요. 새 스크린샷을 찍기 전까지 캐릭터의 이동을 계속 추적하지 않아요. 파일명에는 맵 이름이 없으므로 플레이 중인 맵은 직접 선택해 주세요.

정확히 어떤 폴더를 사용하나요?

문서\Escape from Tarkov\Screenshots

‘문서’나 ‘Escape from Tarkov’ 상위 폴더가 아닌, 원본 스크린샷 파일이 들어 있는 Screenshots 폴더여야 해요. 문서 폴더를 옮겼거나 OneDrive와 동기화했다면 ‘감시 폴더 변경’ 또는 ‘폴더 경로 직접 입력’으로 실제 저장 위치를 지정하세요.

다운로드 없이 브라우저에서만 쓰려면

Chrome·Edge에서 ‘브라우저에서 폴더 연결’을 누르고 Screenshots 폴더를 선택하세요. 브라우저가 백그라운드에 있으면 갱신이 늦어질 수 있어요. 지도 탭으로 돌아와 확인하고, 페이지 새로고침·브라우저 재시작 후에는 다시 연결해 주세요.

‘스크린샷 열기’나 원본 파일 끌어 놓기도 사용할 수 있어요. 이 방식은 파일을 열 때마다 해당 촬영 위치를 한 번 표시해요.

찍었는데 위치가 안 바뀌나요?

  • 먼저 지도 위 ‘스크린샷 추적 상태’에서 연결·읽은 파일·좌표 판독·지도 상태를 확인해 주세요. ‘지금 확인’으로 선택한 폴더를 다시 읽을 수 있어요.
  • 타르코프 게임 자체의 스크린샷이 필요해요. Windows 캡처 도구나 Steam 캡처로 만든 파일에는 타르코프 좌표가 없을 수 있어요.
  • 키를 눌렀을 때 Windows 캡처 화면이 뜬다면 타르코프 설정의 스크린샷 키를 확인하고, 게임이 실제로 파일을 저장했는지 확인해 주세요.
  • 게임이 저장한 원래 파일명을 유지하세요. 파일명을 바꾸거나 메신저에서 다시 저장하면 좌표를 읽지 못할 수 있어요.
  • 다른 맵의 예전 스크린샷일 수 있어요. 현재 맵을 선택하고 게임에서 새로 한 장 찍어 주세요.

파일명만 붙여 넣어도 돼요

층별 지도와 탈출구 보기

  • 지도 오른쪽 층 버튼이나 왼쪽 위 ‘현재 지도 층’에서 그 지도에 실제로 제공되는 층을 선택하세요. 지하·1층·2층·3층·옥상 등의 구성은 맵마다 달라요.
  • ‘촬영 층 따라가기’를 켜면 촬영 높이로 층을 판별할 수 있는 경우에 층을 맞춰요. 판별되지 않으면 직접 선택하세요. 층이 확인되지 않은 목표는 ? 표시를 확인해 주세요.
  • ‘다른 층도 표시’를 켜면 다른 층의 위치도 흐리게 볼 수 있어요. 표시되는 점의 평면 위치가 같아도 실제로는 위·아래층일 수 있어요.
  • 탈출구 아이콘이나 목록을 누르면 이름·진영·조건·등록된 층·출처를 확인할 수 있어요. ‘공용·기타’는 공개 데이터의 분류이며, 협동 탈출 조건은 상세 정보를 확인하세요.
  • 현재 레이드에서 배정되었거나 활성화된 탈출구인지는 이 지도로 확인되지 않아요. 게임의 탈출구 목록과 조건을 함께 확인하세요. 거리 표시는 마지막 촬영 위치에서의 직선거리예요.

위치와 데이터는 이렇게 다뤄요

  • 화면 속 풍경을 추측하지 않고, 게임 자체가 저장한 원본 파일명에서 좌표를 읽어요. 스크린샷 키를 변경했다면 게임 설정에 지정된 키를 사용하세요.
  • 표시되는 위치는 마지막 스크린샷을 찍은 시점이에요. 새로 찍어야 다음 위치로 갱신돼요.
  • 층이 있는 맵에서는 높이 좌표와 지도 층을 함께 확인해 주세요.
  • 스크린샷 원본 이미지는 서버로 업로드하지 않아요. 파일명과 추적 상태는 내 PC에서 처리하고, 퀘스트 기록은 이 브라우저에 저장해요.
  • ‘진단 기록 저장’은 현재 연결·파일명·판독 상태를 JSON 파일로 내려받는 기능이에요. 저장 버튼을 눌렀을 때만 파일이 생성돼요.

퀘스트 수록 범위

tarkov.dev의 공개 데이터에 등록된 퀘스트 전체를 불러와요. 최신 추가·이벤트 임무의 반영은 늦을 수 있어요. 스토리 챕터와 개인별 일일·주간 임무의 완전한 수록은 보장하지 않아요. 목표 좌표가 없는 임무는 목록에서 조건을 확인할 수 있어요.

퀘스트 화면을 캡처해서 찾기

위쪽 ‘퀘스트 캡처’나 퀘스트 목록의 ‘캡처로 찾기’를 누르세요. 이미지를 선택하거나 끌어 놓고, 캡처가 클립보드에 있다면 열린 창에서 Ctrl + V로 붙여 넣으세요. 이미지에서 읽은 이름을 공개 퀘스트 목록과 연결해 상세 내용과 등록된 목표 위치를 찾아요.

잘못 읽은 글자는 ‘인식한 글자 확인·수정’에서 고칠 수 있어요. 한국어 인식 파일은 처음 사용할 때 인터넷으로 받으며, 캡처 이미지는 PC에서 처리해요. 연결한 폴더의 새 캡처도 분석하려면 ‘최신 캡처 자동 분석’을 직접 켜세요.

아이템 시세 확인

왼쪽 ‘아이템 시세’에서 한국어·영어 이름으로 검색하고, 가격순으로 정렬할 수 있어요. ‘60초 자동 갱신’을 켜면 시세 화면에서 공개 데이터를 주기적으로 확인하며, ‘가격 새로고침’으로 직접 확인할 수도 있어요.

최저 등록가·24시간 평균·상인 판매가는 공개 데이터에 제공되는 값이에요. 개별 가격의 기록 시각과 이 화면이 데이터를 가져온 시각을 구분해서 확인하세요. 거래 직후의 변화가 즉시 반영되지 않을 수 있으며, 값이 없는 항목은 등록된 가격처럼 표시하지 않아요.
