Changes: raster tile composition, floor selection, additional Korean labels,
quest/spawn/boss/BTR overlays, route drawings. No original map labels were
recreated. Package includes a manifest with hashes of all generated images.

Night/infected Factory, Ground Zero 21+, and laboratory variants share their
base map drawing when the upstream catalog defines an alias. Transit/open-world
overview images are not separate calibrated raid maps. No live game process,
keypress simulation or automatic screenshot capture is involved.

Freshness: each package carries the matching catalog and artwork revision.
Legacy IndexedDB map configs and unversioned SVG records are ignored. The
service worker uses a new map-cache version, and floor-image URLs include the
asset revision. Windows map images are embedded, available without Internet.
